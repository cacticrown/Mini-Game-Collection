# Mini Game Collection
A fun Collection of Mini Games to play ~~in your classes~~ at home, directly in your favourite Terminal!

## Contributing
Want to add your own minigame? We'd love your help! Just follow these steps:

1. **Fork this project**.
2. **Add your game's `.cs` file** into the `Minigames/` folder.
3. **Make sure your minigame class implements the `IMiniGame` interface** so the menu can load it.
4. **Submit a Pull Request**!
